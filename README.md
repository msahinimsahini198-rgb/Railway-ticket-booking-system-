# Railway Ticket Booking System (MERN)

College-level MERN project with:
- Registration, login and logout
- Train search
- Train details
- Ticket booking
- PNR generation
- My bookings
- Ticket cancellation
- Basic train management pages/APIs without role-based authorization

## Run
### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev

Backend uses MongoDB at `mongodb://127.0.0.1:27017/railway_booking`.
